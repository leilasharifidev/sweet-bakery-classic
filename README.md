# 🍰 Sweet Bakery

A Sweet Little Corner of the Web

**Sweet Bakery** is a front-end bakery website project designed to bring the warm, inviting feeling of a bakery into a clean and visually appealing web experience.

This project is built with **HTML, CSS, and JavaScript**, with a focus on presentation, layout, and creating an enjoyable browsing experience. It is also an opportunity to practice and improve core front-end development skills through a hands-on project.

## ✨ Features

- **Bakery-Inspired Design** — A visual style tailored to a bakery-themed website.
- **Structured HTML** — Clear page structure and semantic markup where appropriate.
- **Custom CSS Styling** — Styling and layouts designed to create a cohesive visual experience.
- **JavaScript Interactions** — Interactive elements implemented with vanilla JavaScript.
- **Responsive Layout** — Responsive behavior as implemented in the project.
- **Organized Codebase** — HTML, CSS, and JavaScript separated into dedicated files for easier maintenance.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Getting Started

You can run this project locally in just a few steps.

1. Clone the repository:

   ```bash
   git clone https://github.com/leilasharifidev/sweet-bakery-classic.git
   ```

2. Open the project folder:

   ```bash
   cd sweet-bakery-classic
   ```

3. Open `index.html` in your browser.

No build tools or package installation are required for the basic static version.
